# Governance Decision Pack

Este pacote contém os documentos prontos de governança e registro de decisões para o padrão de metadados documentais.

## Arquivos

- `decision-register.md`: registro de decisões que explica por que o padrão existe e quais decisões foram tomadas.
- `metadata-governance.md`: documento de governança do padrão.
- `decision-template.md`: template para novas decisões.
- `governance-index.json`: índice estruturado dos documentos.

## Local real neste projeto

```text
frontmatter/governance/decision-register.md
frontmatter/governance/metadata-governance.md
frontmatter/governance/decision-template.md
frontmatter/governance/governance-index.json
```

## Uso

1. Os arquivos já estão em `frontmatter/governance/`.
2. Exija que mudanças relevantes no padrão atualizem o `decision-register.md`.
3. Exija que novos campos passem pelo processo descrito em `metadata-governance.md`.
4. Bloqueie mudanças de schema sem decisão registrada.
